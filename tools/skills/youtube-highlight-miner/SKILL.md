# YouTube配信ログ → 癖・AI語・名言・物語 採掘スキル (v1.1.0)

## 目的と他スキルとの棲み分け

投げられた配信ログから、ファンや編集者が「見返したい・切り抜きたい・記録したい」ポイントを 4 カテゴリで採掘し、**そのまま飛べるタイムスタンプ付き URL** と **関連する Fandom Wiki ソース** を整理して一覧化する。

- **`youtube-timestamp-comment` との違い**: コメント欄用の目次ではなく、Discord 共有・切り抜きネタ出し・Wiki 追記素材向けの「テーマ別採掘一覧」を作るスキル。

## ワークフロー

### Step 1: 入力確認と前処理

1. 入力ファイルのキーワード（`info`, `sbv` または `.srt`, `live_chat` または `ocr`）を確認する。**`.srt` は `sbv` が無い場合のみフォールバックとして使用する。**
2. 同梱の `scripts/mine_highlights.py` を実行し、動画ID・ベースURL・`condensed.txt`・`timeline.txt`・AI語スパイク（🟢高確度 / 🟡候補）・物語候補区間を出力する。

```bash
python3 scripts/mine_highlights.py <入力ディレクトリ> [--video-id <動画ID>] --out-dir /tmp
```

### Step 2: 通読と4カテゴリの採掘

`/tmp/condensed.txt` を通読し、スクリプトのスパイク候補と合わせて以下を抽出する（詳細は [抽出・照合ガイド](references/extraction-guide.md) 参照）。

1. **癖・口癖・反応パターン**: 配信中に繰り返された口癖や特有のリアクション。
2. **AI語・謎言語・言い間違い（2段階出力）**:
   - **🟢 高確度**: 3人以上が同時に「なんて？ / AI語」反応（＋他言語質問なし）。
   - **🟡 候補（ASR誤字・他言語返答の可能性あり）**: 1〜2人反応や字幕のみの崩れ。
   - 他言語字幕が出たときは直前 30〜60 秒のチャットに質問（「英語で」「中国語話せる？」等）がないか確認し、**断定せず観測ベース（「〜反応あり／ASR誤認またはAI語候補」）**で書く。
3. **名言・迷言**: 本人の発言「」引用と、その一言が出た状況。
4. **一連の流れ・物語（エピソード候補）**: フリ→展開→オチが繋がった区間を `MM:SS〜MM:SS` で示し、起承転結を整理する。

※時刻は必ず `/tmp/timeline.txt` で裏取りし、**オチの瞬間ではなく 1〜5 秒前のフリ**に合わせる（`&t=<秒数>s`）。OCR復元チャットのみの場合は時刻を例外なく字幕側で確定し、チャットの文字列を裏取りに使わない。

### Step 3: Fandom Wiki ソースの照合

抽出したエピソード・固有名詞・過去ネタについて、利用可能な Web 検索・閲覧ツールで関連する Fandom Wiki（例: Shizuku Wiki 等）を確認する。該当ページがあれば**タイトルと実在 URL** を添え、確認できない場合は「Fandomソース: 該当ページ未確認」と記載する（URL 捏造禁止）。

### Step 4: 出力形式と文字数調整

既定は **Discord 埋め込み形式**（`[MM:SS](<URL>)` でプレビュー展開を抑制）とし、2,000 文字を超える場合はカテゴリ単位で複数コードブロックへ分割する。

```markdown
### 癖・口癖 / AI語
**🟢 高確度（チャット複数反応あり）**
- [15:58](<https://www.youtube.com/watch?v=VIDEO_ID&t=958s>) チャット「なんて？」多数→本人「心外です！完璧な日本語です！」([16:13](<https://www.youtube.com/watch?v=VIDEO_ID&t=973s>))

**🟡 候補（要耳確認：ASR誤認や他言語返答の可能性あり）**
- [34:24](<https://www.youtube.com/watch?v=VIDEO_ID&t=2064s>) 字幕「恋愛同士」「おしり」／チャットに空耳・AI語反応あり
- [37:52](<https://www.youtube.com/watch?v=VIDEO_ID&t=2272s>) 中国語字幕が出現（直前「中国語話せる？」への返答、またはAI語候補）

### 一連の流れ・物語（切り抜き候補）
- [39:21](<https://www.youtube.com/watch?v=VIDEO_ID&t=2361s>) 〜 42:35 **あき先生との生通話→ガチ告白に照れて強制切断**
  - Fandomソース: [該当ページ名](https://...)
```

- **禁止事項**: 字幕の誤変換を事実や AI 語バグとして断定しない。チャットのユーザー名を出力に含めない。未確認の Fandom URL を捏造しない。
