# YouTubeハイライト・癖・名言採掘 (`youtube-highlight-miner`)

**Current Version: v1.1.0**

`youtube-timestamp-comment` から派生した、配信ログ分析・ネタ採掘特化スキルです。

## 特徴

- **4カテゴリ採掘**: 配信者の「癖・口癖」「AI語・謎言語」「名言・迷言」「一連の流れ・物語があるエピソード」を抽出します。
- **AI語の2段階確度判定**: 取りこぼしを防ぎつつ誤爆を減らすため、**🟢高確度（3人以上反応）** と **🟡候補（ASR誤字・他言語返答の可能性あり）** に分け、直前の他言語質問チェックと観測ベース表記を行います。
- **タイムスタンプ付きURL自動生成**: `info.txt` の動画URLと字幕の秒数を紐づけ、`&t=秒s` 付きのリンク（既定は Discord プレビュー抑制の `[MM:SS](<URL>)` 形式）を生成します。
- **Fandom Wiki ソース紐づけ**: 話題に出た過去企画や設定を Fandom Wiki と照合し、出典リンクを添えます（未確認・未接続時は捏造せず明記）。

## 構成ファイル

- `SKILL.md`: スキル本体
- `scripts/mine_highlights.py`: 字幕（`sbv` / `.srt` フォールバック）・チャット前処理＋AI語2段階スパイク・物語区間候補の自動抽出スクリプト
- `references/extraction-guide.md`: 4カテゴリの抽出基準、AI語誤爆防止ルール、Fandom Wiki 照合ルール、Discord 2,000文字分割ガイド
