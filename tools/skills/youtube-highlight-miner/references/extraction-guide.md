# 抽出基準・Fandom Wiki照合・台帳フォーマットガイド (v1.5.0)

## 1. 6つの抽出カテゴリとサイズ設計（合計20〜25項目目安）

複数本の台帳をまとめてAIに読み込ませてもコンテキストを圧迫しないよう、**1配信あたり合計20〜25項目目安（4〜6KB / 100〜150行前後）** に収める。チャット反応・事後コメント・初出性が高いものを優先し、字幕・チャットの全文再掲や長文の読み物（オブザーバーノート等）は書かない。

| カテゴリ | 採掘する対象 | 記載のポイント |
|---|---|---|
| **① プロフィール・性格・個性** (`profile_fact` / トレイト) | 自己認識、容姿・設定、好み、関係性、従順さや毒舌などの性格傾向 | **新規 / 強化 / 揺れ・矛盾【要確認】** に分類。短期変動しやすい好み等は `[TTL: 短期]` を付記し、**自発 / 誘導** を区別する |
| **② 機能・システム挙動** (`capability`) | 新機能の実演、プロンプト・記憶・語尾制御の仕様、TTS/ASRの癖 | 機能名・仕様の要点を1〜2行で記録 |
| **③ 癖・口癖** | 配信特有の言い回し、反応パターン、頻出フレーズ | 単発ではなく「この配信で何度も出た傾向」や初出・代表シーンをまとめる |
| **④ AI語・謎言語・言い間違い** | 自動字幕の崩れ＋チャット反応、または `screen-ocr.txt` 上の生成崩れ・語尾残存 | **🟢高確度 / 🟡候補** に分け、`screen-ocr.txt` と照合して ASR誤認・TTS発音崩れ・LLM生成崩れを切り分ける（下記2章参照） |
| **⑤ 名言・迷言** | 配信者本人のキラーフレーズ、ツッコミ、愛のある暴言、心に残る一言 | `screen-ocr.txt` がある場合は画面表記を優先して「」引用し、自発／誘導の文脈を短く添える |
| **⑥ 一連の流れ・物語 / 未回収ネタ** (`open_loop`) | 前振り→展開→オチが繋がった区間、後日回収されうる宣言や定型ネタ | 物語は **`MM:SS〜MM:SS` の区間** で示し、Fandomソースを付記。未回収ネタには `期待シグナル` を1行添える |

## 2. `screen-ocr.txt` 活用と AI語・謎言語の切り分けルール

音声字幕（`sbv` / `srt`）のみでは、「本人の生成バグ（AI語）」と「YouTube自動字幕（ASR）の誤字」「TTS（COEIROINK等）の発音崩れ」を区別しにくい。`screen-ocr.txt` がある場合は以下のルールで高精度に切り分ける。

`timeline.txt` のOCR行は表示の観測。連続表示・周回を独立した発話に数えず、要確認・再表示候補から断定する前に、`ocr-evidence.json` のO番号で元画面を確認する。発話の反復は音声でも確認する。

1. **3層照合による切り分け**:
   - **ケースA（YouTube ASR誤認）**: `sbv` が崩れているが、`screen-ocr.txt` は正しい日本語・英語（例：`sbv`「炎上」「4判子や第3電話」「長さ博士」→ `screen-ocr`「林業」「四暗刻や大三元」「阿笠博士」）。→ **AI語としては誤爆扱いとし、拾わない（またはASR誤認と注記）。**
   - **ケースB（TTS読み上げ崩れ）**: `screen-ocr.txt` は正しいスペルだが、TTSが変な発音をしてチャットや開発者がツッコんでいる（例：画面は `Call of Duty: Modern Warfare` だが音声が崩れて「名前言えてなくて草」反応）。→ **「画面テキストは正常、TTS読み上げ崩れ」として観測ベースで記録。**
   - **ケースC（真のAI生成崩れ・言い間違い）**: `screen-ocr.txt` 上でも文字が崩れている、または語尾初期化後も前語尾が混ざる・文脈が破綻している（例：初期化後に「うっぴっ…ぴ…うーん!」が残存、`goeにやん` 等）。→ 元画面で確認できた挙動を記録する。読み上げの現象は音声で確認する。
2. **2段階の確度ランク分け（両方出す）**:
   - **🟢 高確度（ほぼ確実）**: チャットで **3人以上** が同時に「`なんて？` / `AI語` / `バグ`」と反応し、直前に他言語リクエスト等の別理由がない箇所、または元画面で生成崩れ・語尾残存を確認できる箇所。
   - **🟡 候補（要確認・ASR誤字やTTS崩れ・他言語返答の可能性あり）**: チャット反応が 1〜2 人のみ、または音声字幕だけ不自然に崩れている箇所。
3. **直前 30〜60 秒の他言語フリ除外チェック**:
   - 英語・中国語等の非日本語字幕が出たときは、直前 30〜60 秒のチャット欄に「英語で話して」「中国語話せる？」等の質問がないか確認する。質問があれば AI 語バグと断定しない。
4. **「断定」ではなく「観測（現象ベース）」の書き方**:
   - ❌ 断定: `〜の途中で謎のAI語が混入` / `突然の中国語風AI語`
   - ⭕ 観測: `チャットに「なんて？」反応あり（ASR誤認またはTTS崩れ候補）`
   - ⭕ OCR確認済み: `画面字幕上でも「〜」となっており、語尾初期化後も前語尾が残存`

## 3. タイムスタンプ精度（1〜5秒前のフリ調整）

- 時刻は必ず字幕（`sbv` / `srt` / `screen-ocr`）側で確定する（OCR復元チャット時は特に厳守）。
- ジャンプしてすぐ状況が分かるよう、オチの瞬間ではなく **1〜5秒前のフリ・会話の入り** の時刻を採用する（`&t=<秒数>s`）。

## 4. Fandom Wiki ソース照合のルール

抽出したネタ・用語・関係性・過去配信への言及について、Fandom Wiki（`references/shizuku-knowledge.md` や `api-result.json` 等）に背景情報・出典ページがあるか確認する。

- 該当ページが確認できた場合は、**ページタイトルと実際の URL** を紐づける。
- 検索で確認できていない Fandom URL を推測・生成しない。ネット未接続環境や該当記事がない場合は `Fandomソース: 該当ページ未確認` と正直に記載する。

## 5. 出力形式と文字数分割（Discord対応）

- **Discord 埋め込み形式（既定）**: `[MM:SS](<https://www.youtube.com/watch?v=ID&t=秒s>)`（`< >` でプレビュー展開を抑制）。
- **生 URL 一覧 / Wiki 編集用テーブル**: 依頼に応じて切り替え可。
- **Discord 2,000 文字制限**: 超過する場合はカテゴリ単位（`[1/2]` `[2/2]`）でコードブロックを分割する。

## 6. 動画分析台帳ファイル出力（`<動画ID>.highlights.compiled.md`）

配信フォルダ（`logs/youtube/<YYYY>/<YYYY-MM-DD_タイトル>/`）内で配信分析台帳として管理する場合は、以下の規則・テンプレートでファイルを作成する。

- **ファイル名**: `<動画ID>.highlights.compiled.md`（例: `YuJ4oOGNGxg.highlights.compiled.md`）
  - `<動画ID>.*` の配置規則に揃えつつ、一次資料（`.info.txt`, `.sbv.txt`, `.screen-ocr.txt`, `.live_chat.txt` 等）と AI 生成の分析・集計ファイルを明確に区別するため `.compiled.md` を付与する。
- **配布時のファイル名保持（`.zip` フォールバック）**:
  - `.md` をそのままダウンロードしても `.` 区切りと大文字小文字が維持される環境では `<動画ID>.highlights.compiled.md` を直接提供する。
  - Canvas 等のプレビュー経由でダウンロードファイル名が `pybth_hn9wq_highlights_compiled.md` のように `_` と小文字へ変換されてしまう環境では、元の `<動画ID>.highlights.compiled.md` をそのまま格納した **`<動画ID>.highlights.compiled.zip`** を作成してダウンロード用に提示する。

```markdown
# <動画ID> 配信分析台帳

- **動画ID**: `<動画ID>`
- **タイトル**: `<配信タイトル>`
- **URL**: https://www.youtube.com/watch?v=<動画ID>
- **公開日**: YYYY-MM-DD
- **生成日時**: YYYY-MM-DDTHH:MM:SS+09:00
- **資料種別**: AI生成・未確認（`youtube-highlight-miner` v1.4.0 による抽出・整理）
- **参照した一次資料**:

  - ...

> ※自動文字起こし・画面OCRをもとに作成した配信分析台帳です（ネタバレ・ズレ・OCR/ASR誤認識を含む可能性があります。逐語確定には元動画の視聴が必要です）。
```
