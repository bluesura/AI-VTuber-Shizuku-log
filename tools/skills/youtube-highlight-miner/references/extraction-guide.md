# 抽出基準・Fandom Wiki照合・出力フォーマットガイド (v1.1.0)

## 1. 4つの抽出カテゴリと採掘基準

| カテゴリ | 採掘する対象 | 記載のポイント |
|---|---|---|
| **① 癖・口癖** | 配信特有の言い回し、反応パターン、頻出フレーズ（例: 「呆れました」、特有の笑い方） | 単発ではなく「この配信で何度も出た傾向」や初出・代表シーンをまとめる |
| **② AI語・謎言語** | 自動字幕の崩れ＋チャットで「なんて？」「AI語」「空耳」が集中した箇所 | **🟢高確度 / 🟡候補** の2段階に分け、断定ではなく観測ベースで書く（下記2章参照） |
| **③ 名言・迷言** | 配信者本人のキラーフレーズ、ツッコミ、愛のある暴言、心に残る一言 | 発言の「」引用（正規表記）と、その一言が出た文脈・フリを短く添える |
| **④ 一連の流れ・物語** | 前振り→展開→オチが繋がったエピソード（切り抜き・振り返り向け） | 単一時刻ではなく **`MM:SS〜MM:SS` の区間** で示し、起承転結の要約と引き金時刻を付ける |

## 2. AI語・謎言語の「取りこぼさず誤爆を減らす」ルール

テキスト字幕（`sbv` / `srt`）のみでは、「本人の発音バグ（AI語）」と「YouTube自動字幕（ASR）の誤字」や「外国語コメントへの返答」を 100% 区別することはできない。そのため厳密に削りすぎず、以下の 3 ルールで整理する。

1. **2段階の確度ランク分け（両方出す）**:
   - **🟢 高確度（ほぼ確実）**: チャットで **3人以上** が同時に「`なんて？` / `AI語` / `バグ`」と反応し、直前に他言語リクエスト等の別理由がない箇所（または本人も「AI語じゃない」等と反応している箇所）。
   - **🟡 候補（要確認・ASR誤字や他言語返答の可能性あり）**: チャット反応が 1〜2 人のみ、または字幕だけ不自然に崩れている箇所。別枠・参考候補として拾い上げる。
2. **直前 30〜60 秒の他言語フリ除外チェック**:
   - 英語・中国語等の非日本語字幕が出たときは、直前 30〜60 秒のチャット欄に「英語で話して」「中国語話せる？」等の質問がないか確認する。質問があれば AI 語バグと断定しない。
3. **「断定」ではなく「観測（現象ベース）」の書き方**:
   - ❌ 断定: `〜の途中で謎のAI語が混入` / `突然の中国語風AI語`
   - ⭕ 観測: `チャットに「なんて？」反応あり（ASR誤認またはAI語候補）`
   - ⭕ 他言語: `中国語字幕が出現（直前「中国語話せる？」への返答、またはAI語候補）`

## 3. タイムスタンプ精度（1〜5秒前のフリ調整）

- 時刻は必ず字幕（`sbv` / `srt`）側で確定する（OCR復元チャット時は特に厳守）。
- ジャンプしてすぐ状況が分かるよう、オチの瞬間ではなく **1〜5秒前のフリ・会話の入り** の時刻を採用する（`&t=<秒数>s`）。

## 4. Fandom Wiki ソース照合のルール

抽出したネタ・用語・関係性・過去配信への言及について、Fandom Wiki（例: Shizuku Wiki 等）に背景情報・出典ページがあるか確認する。

- 該当ページが確認できた場合は、**ページタイトルと実際の URL** を紐づける。
- 検索で確認できていない Fandom URL を推測・生成しない。ネット未接続環境や該当記事がない場合は `Fandomソース: 該当ページ未確認` と正直に記載する。

## 5. 出力形式と文字数分割（Discord対応）

- **Discord 埋め込み形式（既定）**: `[MM:SS](<https://www.youtube.com/watch?v=ID&t=秒s>)`（`< >` でプレビュー展開を抑制）。
- **生 URL 一覧 / Wiki 編集用テーブル**: 依頼に応じて切り替え可。
- **Discord 2,000 文字制限**: 超過する場合はカテゴリ単位（`[1/2]` `[2/2]`）でコードブロックを分割する。
