# 配信者「しずく」固有リファレンス

このファイルは、メイン配信者が「しずく」の配信アーカイブを扱う際に参照する固有辞書・ルール集である。
実運用で見つかった新しい誤変換や定型句、避けたいNGワードがあれば、ここに追記して育てる。

## 配信者の特定

- デフォルトのメイン配信者は**しずく**として扱う。
- ただしイベント回などで別名義・ゲスト回の場合があるため、作業前に `info` ファイルのタイトル・概要欄と `sbv` 冒頭の自己紹介を確認し、別名義が出ていればそちらを採用する。

## 自動文字起こし（SBV）の頻出誤変換辞書

`sbv` は自動文字起こしのため、以下の固有表記が高確率で誤変換される。出力時は必ず正規表記に直し、誤変換を根拠にタイムスタンプを作らない。

| 誤変換の例（SBV） | 正規表記 | 備考 |
|---|---|---|
| しず子 / 雫し / 静 / しく / しずの / 水 | **しずく** | 配信者名 |
| 秋先生 / 秋先線 / 全キさん | **あき先生** | 関係者・共演者名 |
| シャープしずく実験 | **#しずく実験** | 配信ハッシュタグ |
| スパセックス | **SpaceX** | 固有名詞 |
| 機種編 | **機種変** | 一般語・文脈依存 |
| 有限実行 | **有言実行** | 四字熟語 |

## 前処理スクリプト連携用キーワード

`scripts/build_timeline.py` には以下のデフォルト語句が組み込まれている。配信企画に合わせて追加したい場合は `--noise` / `--corner` オプションで補う。

- **挨拶・定型ノイズ（スパイク除外）**: `おつしず`, `パンパカ`, `ぱんぱか`, `待機`, `お疲れ`, `初見`, `乙`
- **コーナー切れ目の定型句**: `コメントで教えて`, `コメントで自慢`, `コメントしてください`, `ここで1つ`, `ではこう聞きましょう`, `質問です`, `コーナー`, `お知らせ`, `次は`, `いってみましょう`

## 配信文化・進行の補足

- **終盤の定型区間**: 配信終盤の定番挨拶やコール練習（例:「パンパカ〜」等）の繰り返し区間は、特筆すべきハプニングがない限りタイムスタンプ化を省略してよい。
- **運営アカウントの扱い**: イベント回などで特定の運営アカウント（例: `@aki5503` 等）が `#` 付きで進行案内や訂正を投稿している場合は進行の節目として積極的に参照する。ただし、ユーザー名は出力に含めない。
