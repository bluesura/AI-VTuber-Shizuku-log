# YouTubeコメント用タイムスタンプ

指定された配信ログから、YouTubeコメント欄へ貼れるタイムスタンプ付き目次を作るスキルです。

- [SKILL.md](source/youtube-timestamp-comment/SKILL.md)：編集用の正本。
- [youtube-timestamp-comment.skill](youtube-timestamp-comment.skill)：正本をまとめた配布パッケージ。
- `archive/`：過去版。現在の手順の代わりに使いません。

## 作業の範囲

**YouTubeとFandom「動画・配信」の一覧照合・Wiki更新と、タイムスタンプコメント作成は別スキルの作業です。** 一覧照合が必要なら[Wiki編集スキル](../shizuku-wiki/README.md)とログ収集の手順で別途行い、対象動画ID・URLとログの所在をこちらへ引き渡します。タイムスタンプ作成にFandomの照合や更新は必須ではありません。

## 既存確認から手動投稿後の収録まで

1. 保存済みコメントと作業記録を確認します。配信全体を案内できる十分な目次があれば作成を省略します。
2. 単発の時刻だけ・一部の案内だけ・未収録なら、公開コメントを再取得して匿名化したファイルを更新します。
3. 再取得後も不足する範囲だけ、字幕・チャットから案を作ってチャットに返します。曲目一覧や公式チャプターも考慮し、項目数だけで判定しません。取得失敗は保留します。
4. **ユーザーが確認して手動で投稿します。** エージェントは投稿しません。
5. 投稿から最低限2〜3分（運用上は3分）待ってコメントを再取得し、今回の本文を確認してローカルへ収録します。投稿時刻不明なら投稿済みの連絡から3分空けます。公開確認には日時を残し、後日見えなくなった場合も記録します。

```powershell
# リポジトリのルートから、保存済みコメントだけを確認
python tools/scripts/check_youtube_timestamps.py <動画ID> --check-only

# 目次が不足する場合、または手動投稿後の再取得
python tools/scripts/check_youtube_timestamps.py <動画ID> --refresh
```

補助ツールは時刻を検出するだけで、目次として十分かは判定しません。`existing_local` 等や `generate` の値だけで作成・省略を決めず、コメント本文を読んで判断します。

進捗はGit管理外の `outputs/youtube-timestamps/status/<動画ID>.json` に保存し、「投稿待ち」「投稿済み・公開未確認」「公開確認済み」を区別します。投稿後に取得できなくても、スパム等の原因を断定せず、再生成・再投稿を促さずに公開未確認として保留します。生成案を取得済みコメントへ混ぜません。

URL・既存本文の一覧を受け取った場合は、公開コメントと照合して対応一覧を作ります。リスト外の新規候補は作成前に確認し、既存本文の調整は個性を残して1件ずつ提案します。

詳しい判断・コマンド・進捗・公開未確認時の扱いは [既存目次と投稿確認の手順](source/youtube-timestamp-comment/references/existing-timestamps.md)、作成時のログ読解・文体・出力形式は [スキル本体](source/youtube-timestamp-comment/SKILL.md) を参照してください。

更新時は正本から `.skill` を再生成し、作業用ファイルや `__pycache__` を含めないことを確認します。
