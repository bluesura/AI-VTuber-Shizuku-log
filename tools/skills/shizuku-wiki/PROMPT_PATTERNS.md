# shizuku-wiki のプロンプトパターン

やりたい作業に合う依頼文をコピーし、`〈 〉` を対象ページ名や資料に置き換えて使います。リポジトリ内では [shizuku-wiki の SKILL.md](SKILL.md) を参照でき、別の環境では、利用先の形式に合わせてスキルを導入します。[別の環境で使う](../README.md#別の環境で使う)`evidence-first-writing` を併用する場合は、そのスキルも添付します。Wikiに公開する場合は、対象ページと提示済みの差分を指定して承認します。

| やりたいこと | 依頼文 |
|---|---|
| 現在のページソースをまとめて渡す | [作業前の準備](#作業前の準備) |
| 複数の配信・動画と活動の節目を追記する | [配信・動画のまとめ追記](#配信動画のまとめ追記) |
| 最近の報道や外部記事をWeb検索で探す | [メディア露出のWeb調査](#メディア露出のweb調査) |
| 新しい情報の掲載先を判断してもらう | [複数ページの更新案](#複数ページの更新案) |
| Xの投稿や記事をどこに載せるか相談する | [掲載先を相談してから差分を作る](#掲載先を相談してから差分を作る) |
| トップページに更新が必要か調べる | [トップページの点検](#トップページの点検) |
| 既存ページの文章を読みやすくする | [既存ページの推敲](#既存ページの推敲) |
| 更新済みの日本語ページから英語版を作る | [英語版の翻訳全文](#英語版の翻訳全文) |
| Virtual YouTuber Wikiの「Shizuku」を更新する | [外部Wikiとの照合](#外部wikiとの照合) |
| 作業中に見つかったスキルの改善点を確認する | [作業後の振り返り](#作業後の振り返り) |

## 作業前の準備

[主要8ページのAPIレスポンスを開く](https://shizuku.fandom.com/api.php?action=query&prop=revisions&rvprop=ids%7Ctimestamp%7Ccontent&rvslots=main&titles=%E3%81%97%E3%81%9A%E3%81%8F%7C%E5%B9%B4%E8%A1%A8%7C%E5%8B%95%E7%94%BB%E3%83%BB%E9%85%8D%E4%BF%A1%7C%E3%83%A1%E3%83%87%E3%82%A3%E3%82%A2%E9%9C%B2%E5%87%BA%7C%E3%83%95%E3%82%A1%E3%83%B3%E6%B4%BB%E5%8B%95%7C%E5%85%AC%E5%BC%8F%E3%83%AA%E3%83%B3%E3%82%AF%7CShizuku_Lab%7C%E7%B7%A8%E9%9B%86%E8%80%85%E3%81%AE%E6%96%B9%E3%81%B8&format=json&formatversion=2) からJSONを保存し、スキルと依頼文に添えます。対象は「しずく」「年表」「動画・配信」「メディア露出」「ファン活動」「公式リンク」「Shizuku Lab」「編集者の方へ」です。`rvprop=ids|timestamp|content` で本文に加えてリビジョンIDと更新日時を取得できます。[MediaWiki Revisions API](https://www.mediawiki.org/wiki/API:Revisions)

トップページや英語版を渡す場合は、正式なページ名を `titles` に追加するか、そのページのソースを別途添付します。トップページの正式名は `query.general.mainpage` で確認できます。[Shizuku Wikiのサイト情報JSON](https://shizuku.fandom.com/api.php?action=query&meta=siteinfo&siprop=general&format=json&formatversion=2) · [MediaWiki Siteinfo API](https://www.mediawiki.org/wiki/API:Siteinfo)

取得したJSONを添付するときは、依頼文の冒頭に次を加えます。

```text
添付のJSONは、Shizuku Wikiから取得したページのソースです。対象ページは query.pages の title で特定し、revisions[0].slots.main.content を取得時点のWikitextとして使ってください。revisions[0].revid があれば、差分案に基準リビジョンとして添えてください。必要なページが入っていない場合や、取得後の更新が分かった場合は、該当ページの現行ソースを確認してください。取得できなければ、必要なページ名を教えてください。
```

以前の `rvprop=content` のJSONも本文の共有に使えます。公開を承認した後は、反映直前に現行リビジョンと本文を照合します。[記事ワークフロー](references/article-workflow.md)

## 配信・動画のまとめ追記

```text
shizuku-wiki スキルを主基準に、添付した配信・動画の情報やURLをもとに、[[動画・配信]] と [[年表]] の追記案を作ってください。年表の地の文には同梱の日本語推敲工程を使い、別の日本語推敲スキルを添付していれば併用してください。

「動画・配信」は既存の行と動画IDで照合し、掲載対象の未掲載動画について、公開日・正式タイトル・長さを元のYouTube情報で確認してください。ライブ配信の本数や年別内訳の変更が必要なら、置換差分も示してください。
「年表」は初配信や新衣装のお披露目など、しずくの活動の節目として掲載基準を満たす出来事を、根拠を添えて提案してください。

ページごとに挿入位置と出典付きのWikitext差分を示してください。日付などを確認できなかった項目は確認事項に挙げてください。今回は差分案の提示までお願いします。

配信・動画の情報またはURL
〈YouTube URL、配信日、節目にあたる出来事の情報など〉

「動画・配信」と「年表」の現行Wikiソース
〈Fandomのソースエディタでコピーした各ページの全文、または添付JSON〉
```

[動画・配信の手順](references/page-videos-streams.md) · [年表の手順](references/page-timeline.md)

## メディア露出のWeb調査

```text
shizuku-wiki スキルを主基準に、最近のしずくに関する報道・取材記事・外部組織の発表を日本語と英語のWeb検索で調べ、[[メディア露出]] の追記候補を挙げてください。

現行ソースの掲載内容と照合し、元記事の公開日、発信主体、独自取材や当事者発表の有無を確認してください。候補ごとに日付、媒体、種別、概要、URL、掲載理由を示してください。掲載判断に必要な日付や本文を確認できなければ、保留理由を教えてください。

検索期間（任意）
〈例：直近1か月〉

「メディア露出」の現行Wikiソース
〈Fandomのソースエディタでコピーした全文、または添付JSON〉
```

掲載したい候補が決まったら、次の依頼文で差分を作れます。[メディア露出の手順](references/page-media-coverage.md)

```text
〈採用する候補の番号・記事名〉を「メディア露出」に追記する案を作ってください。既存行を目印にした挿入位置と、出典付きのWikitext差分を示してください。今回は差分案の提示までお願いします。
```

## 複数ページの更新案

```text
shizuku-wiki スキルを主基準に、下の資料からShizuku Wikiのどのページ・節を更新するか判断してください。evidence-first-writing スキルも添付していれば併用してください。

現行ソースと照合し、既出の情報は重複させず、掲載先ごとに何をどの粒度で書くか示してください。投稿者と情報の出どころを確認し、日付・実施内容など出典で確認できた範囲を使ってください。掲載を保留する事項には理由を添えてください。

採用する案は、対象ページ、追記または置換の位置、目印になる既存行、出典付きのWikitext差分を示してください。連動するページや英語版に追随が必要なら、該当ページを挙げてください。今回は差分案の提示までお願いします。

新情報・一次資料のURL・添付画像
〈ここに入力〉
```

たとえば Reachy Mini と Raspberry Pi の投稿を一緒に渡す場合は、投稿ごとにURLが分かる形で添え、掲載の要否をそれぞれ判断してもらいます。[Shizuku AI技術部の投稿](https://x.com/ShizukuResearch/status/2123974682550603835) · [仕組みを説明する続きの投稿](https://x.com/ShizukuResearch/status/2123974682898735537) · [あき先生の投稿](https://x.com/cumulo_autumn/status/2049767063653364214)

### 掲載先を相談してから差分を作る

```text
shizuku-wiki スキルを参考に、下記のXの投稿や記事をWikiのどのページ・節にどう反映するか、一緒に検討してください。

内容ごとに掲載候補のページ・節と、そこに書く内容、掲載を勧める理由を示してください。候補が複数ある場合は、各ページで扱う範囲を教えてください。根拠や掲載先の判断に迷う項目は、確認したい点を質問してください。

掲載先と書く内容が決まったら、現行ソースを照合し、挿入位置が分かる出典付きのWikitext差分を提案してください。ソースを取得できない場合は、必要なページ名を教えてください。今回は差分案の提示までお願いします。

Xの投稿や記事の本文・URL
〈ここに入力〉

掲載候補ページの現行Wikiソース（手元にあれば）
〈ここに入力〉
```

## トップページの点検

```text
shizuku-wiki スキルに沿って、添付したShizuku Wikiのトップページのソースを点検してください。ニュース・告知の鮮度、終了済み企画の案内、主要ページへの導線、リンク切れ、最新の年表や公式発表との食い違いを確認してください。

修正候補があれば、対象箇所、現状、確認した根拠、優先度を示してください。判断に使った日付と未確認事項も添えてください。更新すべき箇所が見当たらなければ、確認した範囲を教えてください。今回は点検結果の報告までお願いします。

トップページのソース・照合したい資料
〈ここに入力〉
```

## 既存ページの推敲

```text
shizuku-wiki スキルを主基準に、〈ページ名・対象節〉の文章を読みやすくしてください。evidence-first-writing スキルも添付していれば併用してください。

事実関係、引用、出典、リンク、テンプレート、表のWikitext記法を保ちながら、読みにくい箇所を推敲してください。判断に必要な情報が足りなければ、その箇所について質問してください。出典や内容に問題を見つけた場合は、確認事項として挙げてください。

本文は置換箇所が分かるWikitext差分で提示してください。節の順番や見出し、他ページに移す内容に改善案があれば、最後の「構成案」に挙げてください。今回は提案までお願いします。

現行Wikitext・参考URL
〈ここに入力〉
```

## 英語版の翻訳全文

```text
shizuku-wiki スキルと translation-guide.md に沿って、更新が済んだShizuku Wikiの日本語ページを、同じWikiの対応する英語ページに翻訳してください。

日本語の更新済みソースと英語版の現行ソースを照合し、英語版で合意済みの見出し・訳語・リンク先を使ってください。対応ページがない場合や、英語版に独自の記述がある場合は、その扱いをページごとに教えてください。

対象ページ名を明記し、見出し・表・出典・日付・内部リンク・テンプレート・カテゴリの欠落や記法崩れを確認したうえで、ページごとにWikitext全文を出力してください。複数ページが長い場合は、検証済みの .wikitext ファイルをZIPにまとめても構いません。未確定の訳語があれば候補を添えてください。今回は翻訳の出力までお願いします。

翻訳対象のページ名・更新済みの日本語ソース・現行の英語ソース
〈ここに入力〉
```

英語ページ名はスキルの対応表を確認します。たとえば `Shizuku Lab (EN)` は `Shizuku Lab` の英語ページ名で、「編集者の方へ」は日本語ページを参照します。[翻訳ガイド](references/translation-guide.md)

## 外部Wikiとの照合

```text
添付の shizuku-wiki スキルとShizuku Wikiの現行ソースを参考に、Virtual YouTuber Wikiの「Shizuku」の更新案を作ってください。
https://virtualyoutuber.fandom.com/wiki/Shizuku

編集先の現行ソースと編集方針を確認し、Virtual YouTuber Wikiの文体・テンプレート・掲載基準・ライセンスを優先してください。情報の照合はShizuku Wikiの記述を優先して始め、採用する記述は元の公式発表・配信・報道など、編集先で使える出典で確認したうえで書き下ろしてください。

所属・日付・プロフィールなどに明らかな重大な食い違いがあれば、該当箇所の編集案を作る前に、両方の記述と確認できた出典を示して私に判断を求めてください。Virtual YouTuber WikiからShizuku Wikiに取り入れられそうな事実や構成があれば、掲載先と根拠を添えて「Shizuku Wikiへの取り込み候補」に挙げてください。

今回は、Virtual YouTuber Wiki向けの出典付きWikitext差分と、Shizuku Wikiへの取り込み候補の提示までお願いします。
```

編集先ごとの進め方は [外部Wiki・百科事典との連携ワークフロー](references/external-wikis-sync.md) を参照してください。

## 作業後の振り返り

```text
今回の shizuku-wiki スキルを使った作業を振り返って、スキルや手順書に更新・改善すべき箇所があったか教えてください。

ガイドだけでは判断できなかったこと、手順どおりに進めて詰まったこと、新しく確定した訳語や出典の扱い、こちらからの修正指示を確認してください。改善候補があれば、今回起きたこと、該当ファイルと節、変更案を短い差分で示してください。候補がなければ、その旨を一言で教えてください。今回は改善候補の提示までお願いします。
```
