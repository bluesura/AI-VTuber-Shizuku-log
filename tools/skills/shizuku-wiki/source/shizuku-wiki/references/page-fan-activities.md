# ページ手順：ファン活動

対象ページ：`ファン活動` / `Fan Activities`

**ご主人様が参加しやすい導線をまとめる場所**。活動の記録ではなく、これから参加する人への案内として書く。「どこへ行けば何ができるか」が分かる状態を保つ。

前提として `SKILL.md` §0（ソース受領・入力モード・差分出力）と §3（共通ルール）を満たしていること。

---

構成そのものは動かさない。追加が必要な場合は、既存セクションの中に収まらないかを先に検討する。

## 2. ファン制作物の扱い

`tone-style-guide.md` §10 の「複製」と「リンク」の区別に従う。

### 複製（Wikiに取り込む）は原則しない

ファンアート・LoRA・音声などをWikiページ上に埋め込まない。掲載理由がある場合はトークページで確認してから。

### リンクは条件付きで可

ファン制作物は、次の条件をすべて満たせばリンクで紹介してよい。

- **作者自身が公開している場所への直リンクのみ**。第三者による再配布ミラーは不可
- 作者の表示名または `@アカウント名` を必ず併記する
- 作者から取り下げの申し出があれば**即座に除去**し、経緯をトークページに残す
- リンク先が失効した場合は**行ごと除去する**。「かつて公開されていた」という記述だけを残さない
- 公式のキャラクター利用ガイドラインに反する用途を助長するものは載せない

記載例：

```
* Shizuku v1.0（[https://x.com/8co28 @8co28] 制作） - [URL X投稿] / [URL 配布先]
```

配布先が複数ある場合も、**作者本人が案内している配布先だけ**を並べる。

---

## 3. 公式ガイドラインの転記

キャラクター利用ガイドラインの本文は公式が管理しており、Discord等で更新される。Wiki側に転記した内容は必ず古くなる。

- 転記した内容には `{{時点情報|YYYY-MM-DD}}` を付ける
- 「最新の内容は [[Shizuku Lab]] のDiscordチャンネルで確認」という案内を必ず残す
- 公式ガイドラインの原文を長く写さない。要点を自分の言葉でまとめ、確認先へ誘導する

ガイドラインの変更を受け取ったら、`{{時点情報}}` の日付も同時に更新する（置換型の差分）。

---

## 4. Discord招待リンクの扱い

Discordの招待リンクは失効することがある。

- 招待リンクを直接載せる場合は `{{時点情報|YYYY-MM-DD}}` を付ける
- 公式サイト経由の案内（「公式サイトの招待リンクから参加」）も併記し、直リンクが切れても辿り着ける状態にする
- `公式リンク` ページにも同じ招待リンクがある。片方を更新したら**もう片方も同時に更新する**（`SKILL.md` §2 の連動表）

---

## 5. 連動チェック

| 更新内容 | 連動先 |
|---|---|
| ハッシュタグの追加・変更 | `ハッシュタグ` ページ（詳細はそちらが本体） |
| Discord招待リンクの変更 | `公式リンク`、しずくページ「しずくのいる場所」 |
| 二次創作ガイドラインの変更 | `Shizuku Lab` ページ |

判定結果は必ず一行で報告する。
