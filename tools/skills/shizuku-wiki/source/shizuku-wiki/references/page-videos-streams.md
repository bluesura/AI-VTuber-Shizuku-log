# ページ手順：動画・配信

対象ページ：`動画・配信` / `Videos and Streams`

しずくが公開したライブ配信と通常動画の一覧。**通常運用ではこの2種の網羅が目的**であり、面白さや重要度で取捨選択しない。切り抜き中心のショートは既定の照合・追加対象から外すが、取得実装は任意機能として残す。

前提として `SKILL.md` §0（ソース確認・入力モード・差分出力）と §3（共通ルール）を満たしていること。

---

## 0. 「動画・配信ページを更新して」の自動フロー

ユーザーが「wikiの動画・配信ページを更新して」「動画・配信ページを最新にして」など同趣旨の依頼をした場合は、次を標準フローとする。

1. `scripts/update_videos_streams.py check` を実行する
2. MediaWiki APIから `動画・配信` の現在のソースと基準リビジョンを取得する
3. 公式YouTubeの `/streams` と `/videos` を `yt-dlp` で照合する。`/shorts` は既定では照合しない
4. 未掲載IDだけを追記し、ライブ配信の総数と年別内訳だけを再集計した差分案を表示する
5. 保存された確認案のパスと、手動確認が必要な項目を報告する
6. **その差分へのユーザーの明示承認を待つ。この段階では編集しない**
7. 承認後に限り、手順5で表示された確認案を指定して `scripts/update_videos_streams.py apply --plan <確認案のパス> --yes` を実行する
8. 反映前の競合検査と、反映後のリビジョンID・追加IDの検証結果を報告する

確認処理は公開APIを匿名で読み、認証情報を使わない。反映時の認証情報は `SHIZUKU_FANDOM_BOT_USERNAME` と `SHIZUKU_FANDOM_BOT_PASSWORD` からだけ読む。値を表示、ログ出力、ファイル保存してはならない。反映時に未設定なら環境変数名だけを案内する。

ショートも一時的に確認したいとユーザーが明示した場合だけ、`check --include-shorts` を使う。通常の「動画・配信ページを更新して」ではこのオプションを付けない。

確認案のファイル名には基準リビジョンと差分ハッシュが含まれる。`apply --plan ... --yes` は、ユーザーへ表示した**同じ確認案**を指定し、そこに保存されたページ名、基準リビジョン、本文ハッシュ、追加ID、再構築結果がすべて一致した場合だけ編集する。確認後にWikiが更新されていた場合は反映せず、`check` からやり直す。

スクリプトが利用できない実行環境に限り、以下の手動手順へフォールバックする。

---

## 1. 既存ソースから掲載済みIDを抽出する

取得または貼り付けられたwikiソースを解析し、掲載済みの全エントリから動画IDを抽出する。

- `[https://www.youtube.com/watch?v=VIDEO_ID タイトル]` の形式からIDを取る
- **すべてのセクションを対象にする**（`== 2023年アーカイブ ==` `== 2026年アーカイブ ==` `== 通常動画 ==` `== ショート ==`）
- 抽出したIDは、次のステップで「掲載済み」と判定するために使う

---

## 2. 未掲載エントリの情報を集める

### モード1：ユーザーが貼ったテキストから取る

ユーザーがYouTubeの一覧やタイトルを貼る。その中から、ステップ1で抽出したIDに**含まれないものだけ**を拾う。

### モード2（自動フローの既定）：`yt-dlp` またはWebアクセスで取得する

```
https://www.youtube.com/@aivtuber_shizuku/streams   ライブ配信一覧（アーカイブ）
https://www.youtube.com/@aivtuber_shizuku/videos    通常動画一覧
https://www.youtube.com/@aivtuber_shizuku/shorts    ショート一覧（`--include-shorts` 指定時のみ）
```

YouTubeはJavaScriptレンダリングのため、一覧ページのHTMLだけで判断しない。`yt-dlp` のメタデータから動画ID、正式タイトル、公開日時、長さ、配信状態を取得する。取得できなかったものは自動追加せず、手動確認リストへ回す。

### 日付の扱い（最重要）

- YouTubeの**相対表記（「3週間前」「1年前」）は使用禁止**。そこから逆算もしない
- 相対表記しか得られない場合、個別ページ（`https://www.youtube.com/watch?v={VIDEO_ID}`）の説明欄・メタデータ・`og:description` から `YYYY-MM-DD` を特定する
- それでも特定できないときは、日付欄を**空欄のまま**にし、手動確認リストへ回す
- 「ごろ」「不明」「推定」は一切使わない
- 時刻が判明している場合のみ `HH:MM` を付記する。概算なら `~21:02`

---

## 3. 各エントリの項目

| 項目 | 内容 |
|---|---|
| 公開日時（JST） | `YYYY-MM-DD` または `YYYY-MM-DD HH:MM`。不明なら空欄 |
| タグ | 下記タグ分類表から。判断できなければ空欄 |
| 時間 | `H:MM:SS` または `MM:SS`。不明なら空欄 |
| タイトル | YouTubeのタイトルを**そのままコピー**。改変しない |
| URL | `https://www.youtube.com/watch?v=VIDEO_ID`。短縮しない |

タイトルの `【】` はそのまま維持する（`[ ]` に置き換えると外部リンク構文が壊れる）。

### タグ分類表

タイトルから判断できるものだけ付ける。判断できなければ空欄でよい。

| タグ | 判断基準 |
|---|---|
| 雑談 | 「雑談」「おしゃべり」「お話し」を含む |
| ASMR | 「ASMR」「バイノーラル」「朗読ASMR」を含む |
| 歌枠 | 「歌枠」「歌配信」「歌います」を含む（ライブ配信） |
| 歌ってみた | 「歌ってみた」を含む（通常動画） |
| ゲーム | 「マインクラフト」「Minecraft」「APEX」「ゲーム」などを含む |
| 企画 | 「裁判」「AI裁判」「大喜利」「クイズ」「選考会」「マシュマロ」「エイプリルフール」「七夕」「ハロウィン」「逆転」「指導」、または「ギャル化」「やばたにえん」「AIギャルゲ／AIギャルゲー」など衣装・キャラクター・テーマを一時的に変える単発企画を含む |
| 記念 | 「初配信」「記念」「突破」「ただいま」を含む。**ただし「安田記念」「宝塚記念」のようなレース名等、固有名詞の一部として「記念」が出てくる場合は対象外**（しずく自身の節目でなければ記念タグにしない） |
| 耐久 | 「耐久」を含む |
| おでかけ | 「おでかけ」「水族館」「潜入」など外出系を含む |
| 紹介 | 「初見向け」「分かる」「紹介」など説明系を含む |
| レポート | 「GDC」「展示会」「レポート」など外部イベントを含む |
| まとめ | 「まとめ」「総集編」を含む |
| 同時視聴 | 他者の配信・動画・中継をリアルタイムで一緒に視聴する形式で、その視聴対象なしには成立しないコンテンツ。「同時視聴」「実況」「vs」+対戦相手名、競馬の重賞名（「安田記念」「宝塚記念」「日本ダービー」等）による競馬予想配信、スポーツ中継の同時視聴などを含む |

**この13個以外のタグを新設しない。** 新しい分類が必要だと判断したら、勝手に作らずユーザーへ提案する。タグを追加した場合は `translation-guide.md` §8 の対訳表にも必ず追記する（片方だけに増えると英語ページで訳せなくなる）。

### 配信種別の振り分け

| 種別 | 追加先 |
|---|---|
| ライブ配信アーカイブ | 該当年の `== 20XX年アーカイブ ==` |
| 通常動画（ライブ配信でない） | `== 通常動画 ==` |
| ショート（公式YouTubeの `/shorts` 掲載動画） | 既定では追加しない。ユーザーが明示的に含めた場合のみ `== ショート ==` へ追加する（セクションがなければ `== 通常動画 ==` の後に新設）。60秒を超える動画も公式タブに掲載されていれば含める |

## 4. 手動確認リスト

日付を特定できなかったエントリを、差分とは**別に**まとめて出力する。

```
【手動確認が必要な動画・配信】
以下は投稿日を特定できませんでした。各URLを直接確認して日付を補完してください。

1. タイトル: {タイトル}
   URL: https://www.youtube.com/watch?v={VIDEO_ID}
   備考: {理由。例「個別ページでも日付の記述が見つからなかった」}
```

すべて特定できた場合は「すべての日付を特定できました」と一言添える。

---

## 5. 差分の作り方

### テーブル行の追記

- テーブルは**新しい日付順（降順）**。新規エントリは、日付が直後に来る既存行の**直前**に挿入する
- 年をまたぐ場合は年ごとにセクションを分ける
- 日付・タグ・時間が空欄の行は、該当セルを空白のまま残す
- `class="wikitable sortable"` を必ず維持する
- **既存エントリの内容（タイトル・URL・タグ・時間・日付）は一切変更しない**

### 配信状況欄の再集計（置換）

ライブ配信の本数と年別内訳を数え直し、**置換型の差分**として出力する。

```
【置換】対象: 配信状況セクション
置換前: ライブ配信 62本（2023年 48本 / 2026年 14本）
置換後: ライブ配信 63本（2023年 48本 / 2026年 15本）
```

置換前の文字列は、取得または貼り付けられたソースから**そのままコピー**する。記憶で書かない。

---

## 6. 連動チェック（必須）

追加した配信が**節目**にあたる場合は、年表にも出来事として追記する。

節目の例：初配信、V2.0初配信（2度目の初配信）、登録者数の記念配信、初めての形式（初の耐久配信・初のおでかけ配信）、コラボ配信。

通常の配信は年表に載せない。年表は生涯の年代記であり、配信の一覧ではない。

判定結果は必ず一行で報告する。

```
年表：該当なし（通常の雑談配信のため）
年表：追記対象（初のおでかけ配信のため）→ 差分を併せて出力
```

---

## 7. 注意事項

- 既存エントリは書き換えない。追加と本数更新のみ行う
- タイトルはYouTubeのものをそのままコピーする。読みやすく整えない
- Wikiへ追加する行はMediaWiki記法にする。自動更新時の監査用統一差分はそのまま提示してよい
- 英語ページ（`Videos and Streams`）を更新する場合は、タグを `translation-guide.md` §8 で英訳し、タイトルは日本語のまま残す（動画の実タイトルであるため）
