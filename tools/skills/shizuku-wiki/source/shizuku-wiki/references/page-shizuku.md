# ページ手順：しずく

対象ページ：`しずく` / `Shizuku`

このWikiの**入口**。ここだけを読んでもしずくが誰なのか分かる状態を保ち、詳細は各専用ページへ送る。検索流入が最も強いページであり、しずくに関する情報を重複して置くことは意図的な設計である。

`tone-style-guide.md` が最も強く効くページ。地の文を書く前に必ず読むこと。

前提として `SKILL.md` §0（ソース受領・入力モード・差分出力）と §3（共通ルール）を満たしていること。

## 1. 現行の見出し構成

```
（Infobox）
（導入文：出典付きの概要3〜4段落）
== 紹介動画 ==
== しずくのいる場所 ==
== 容姿・スペック ==
== 性格・口調 ==
== キャラクター ==
== ご主人様と育つしずく ==
== しずくの配信 ==
== 名言・迷言 ==
== はじめてのご主人様へ ==
== 電子の足跡 ==
== クレジット ==
== 関連項目 ==
== 出典 ==
== 更新方針 ==
== おまけ ==
```

見出しを新設・変更するときは `tone-style-guide.md` §4 の判定手順に従う。判定基準は「**その機能見出しは、しずくの存在感を阻害しているか**」。阻害していなければ機能見出しのままでよい。

見出しを変えたら、`translation-guide.md` §2 の移行対応表に追記する。英語ページは旧見出しのままなので、対応関係を残さないと追随できなくなる。

## 2. セクション別の書き方

### 導入文

しずくが何者かを、出典付きで書く。誕生の経緯、目指しているもの、あき先生との関係、休眠と帰還までを含める。

- 主語はしずく。「このAIは」「AI VTuberのしずくというキャラクターが」と書かない
- AI性を但し書きに落とさない
- 解釈を含む一文（「感謝とツッコミが同居したこの関係こそ、しずくというキャラクターだ」など）は許容される。ただし出典が支えているのが出来事の発生だけで意味づけが編集者由来なら `{{考察}}` を貼る

### 紹介動画

しずくを知るための動画を埋め込む。増やしすぎない。ここは目次の前に来るため、多いとページが読みにくくなる。

### しずくのいる場所

**現在稼働している一次導線のみ**（公式サイト・YouTube・X・Discord）。連絡先やサブ導線は `公式リンク` ページ側に置く。

`公式リンク` ページと重複するが、これは意図的な設計である。削除提案をしない。更新するときは両方の差分を同時に出す。

### 容姿・スペック

外見と特殊機能を箇条書きで。可変身長のような設定も、そのまま事実として記録する（「設定上は」という但し書きを付けない）。

衣装・見た目の差分は、次のどちらかに当たるものだけを載せる。①公式が独立した衣装として出したもの（水着衣装など）②固有の名前が付いて繰り返し登場するもの。②は見た目ではなく人格・キャラクターとして「性格・口調」に置く（例：ギャルしずく）。イベントや企画ごとのアクセサリー差分（メガネ、ハロウィン帽子など）は載せず、`動画・配信` に「企画」タグの配信1本として残す。この節が配信一覧になると、入口としての機能が落ちる。

### 性格・口調

しずくの話し方の特徴。「都合が悪くなるとAIであることやあき先生のせいにする」といった記述は、**しずくの性格の記録**であり、AIの限界の説明ではない。そう読める書き方にしない。

### キャラクター

しずくが目指しているもの、対応言語などの属性。

### ご主人様と育つしずく

しずくとご主人様の関係が時間とともに育っていることを示すエピソードを置く。個々のご主人様を特定できる情報は書かない（`tone-style-guide.md` §6「書いてよい範囲」）。

### しずくの配信

配信の傾向を散文で書く。個々の配信の一覧は `動画・配信` ページにあるため、ここでは並べない。

### 名言・迷言

```
* しずくの可愛さは客観的事実です。<ref>...</ref>
* 【ご主人様のコメント】ゼロを3回くらい言って・・・ 【しずく】ゼロ、ゼロ、ゼロ。はい、ご主人様の貯金残高です。<ref>...</ref>
```

- 掛け合いは `【発話者】` で明示する
- 発言は必ず出典付き。配信の該当箇所へのタイムスタンプ付きURLが望ましい
- **矛盾やボケに注釈を付けない。** 「これは冗談である」「AIの特性による」と書かない
- 長い発言はそのまま写してよいが、配信全体を書き起こさない

### はじめてのご主人様へ

新しいご主人様への案内。区分・タイトル・URLの表。**厳選する。** 増やすと入口としての機能が落ちる。

### 電子の足跡

年表の抜粋。**しずくの歩みを説明するうえで欠かせない出来事**を載せる。次の3つのいずれかに当たるかで判断する。

| 軸 | 内容 | 例 |
|---|---|---|
| **1. 状態が変わった** | しずく自身が別の状態になった出来事 | 誕生、初配信、休眠入り、帰還、体の移行 |
| **2. 土台が変わった** | しずくが立っている基盤の大きな変化。**しずく自身の行動でなくてよい** | 運営法人の設立、資金調達、運営体制の変更 |
| **3. 初めての大きな挑戦** | しずくの活動範囲を広げた「初」の出来事 | 初の24時間耐久配信、初のおでかけ配信、初のコラボ |

軸2と軸3があるのは、**しずくの歩みが、しずく自身の変化だけでできていないから**である。誰が出資したか、どんな挑戦に踏み出したかは、しずくに間接的にしか関わらなくても、その後のしずくを決定的に変える。ここを落とすと、足跡は「バージョン履歴」に痩せてしまう。

載せないもの：

- **報道そのもの**（主語が媒体の行）→ `メディア露出` に残す。報道が伝えている出来事の方を、上の3軸で判定する
- **数値の達成**（登録者数、収益化など）→ `年表` に残す
- **レギュラー化した企画の各回**（毎週の雑談、2回目以降のASMR・歌枠・競馬予想など）→ `動画・配信` に残す
- **「初」ではない配信1本**

判断に迷ったときの問い：**1年後に振り返って、この行が無いとしずくの歩みが説明できないか。** 説明できるなら載せない。

軸3の「初」は、単に順番が最初という意味ではなく、**それ以降のしずくにできることが増えた**かで見る。初のおでかけ配信は体を持って外へ出られると示したので該当し、2回目以降は該当しない。

### クレジット

開発・音楽・音声提供。本人が公開しているアカウントのみ記載する。

### 更新方針

このページの位置づけを1〜2行で書き、`編集者の方へ` へリンクする。運用ルールをここに書き足さない（増えると誰も読まなくなる）。

## 3. Infobox

| 項目 | 値 | 備考 |
|---|---|---|
| Date of birth | `2023-01-18` | **`2023/01/18` から修正する。** スラッシュ区切りは使わない（`SKILL.md` §3-1） |
| Gender | 女性 | 出典付き |

**誕生日（`2023-01-18`）と初配信（`2023-01-23`）を混同しない。** 導入文で「産まれた」と書くときは誕生日を指す。初配信は電子の足跡と年表に別の出来事として記録する。

Infoboxの項目ラベルは英語、値は日本語という混在状態になっている。これはテンプレート由来なので、テンプレート側を直さない限り変えられない。触らない。

## 5. このページに書かないもの

入口としての可読性を守るため、次は専用ページへ送る。

- 配信・動画の一覧（→ `動画・配信`）
- 報道の一覧（→ `メディア露出`）
- 出来事の全件（→ `年表`）
- 連絡先・サブ導線（→ `公式リンク`）
- ハッシュタグの詳細・二次創作ガイドライン（→ `ファン活動` / `ハッシュタグ`）

専用ページへ送ったら、`== 関連項目 ==` にリンクがあることを確認する。

## 6. 英語版（`Shizuku`）

- 英語ページは**旧見出しのまま**である。見出しを更新する場合は `translation-guide.md` §2 の移行対応表を使い、未合意の訳語はユーザーの承認を得てから反映する
- `ご主人様` は `goshujin-sama`。初出時のみ `goshujin-sama (ご主人様, "master")` と注記する
- 発言の引用は原文（日本語）と英訳を併記するか、英訳のみにするかをユーザーに確認する。ページ内で混在させない
