# ページ別文章品質プロファイル

| 種別 | 強度 | 実行 | 編集で重視するもの |
|---|---|---|---|
| しずく本人ページ | 強 | yomiyasu局所推敲 + deslop診断（長文で必要時）+ 読みやすさ | 初見でも理解、本人の輪郭、読み物としての流れ。ページ見出しと紹介の密度は`page-shizuku.md`優先 |
| 企画・特集 | 強 | yomiyasu + 構成の確認 + 必要時追加診断 | 具体的な出来事と前後関係、読者が続きを読みたくなる自然な文脈。演出で捏造しない |
| 年表 | 推敲は軽 | 不明瞭な説明のみyomiyasu。意味的レビューは全追加・置換項目で必須 | しずくの生涯の記録。試作・デモ・発表・実運用を区別し、技術的例外は理由を記録 |
| メディア露出 | 軽 | 必要時のみ推敲 | 媒体別の事実、リンク・一次発表との区別、出典の保全 |
| 公式リンク | 原則なし | 正式名称・URLの検査のみ | 情報アクセスの正確性 |
| 動画・配信 | なし（案内文のみ軽） | 既存の専用更新スクリプトを優先。冒頭・配信状況・更新方針など表外の地の文のみ必要時に局所推敲 | 網羅性、テーブル形式、リンク一致、表内データ非改変 |
| ファン活動 / Shizuku Lab | 中 | 案内文が読みにくい場合のみyomiyasu | 実際に参加できる経路・ルール・サーバー内の機能が明確であること |
| 運用ガイド（編集者の方へ 等） | 中 | 必須ルールと任意推奨の切り分け確認 + 読みやすさ | 最低限守るべきルールと推奨ガイドの区別、初心者が最初の一歩を踏み出しやすい導線 |
| 翻訳 | 別工程 | `translation-guide.md`最優先 | 日本語訳にない事実を加えず、日英の対応を保つ |

全ページで`SKILL.md`と`tone-style-guide.md`を守る。上記は文章改善工程の強度であり、既存のガイドを置換しない。

年表の意味的レビューは、文法的に自然な文や推敲しなかった行にも適用する。`page-timeline.md` §2-1・§7と `workflow.md` の審査記録を使う。
