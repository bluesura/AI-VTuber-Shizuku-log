# wiki起草の手引き（draft_wiki v1）

ステップ5の handoff ファイルを、実際のwiki差分に変える工程です。
**このチャットには shizuku-wiki スキル（.skillファイル）を必ず併用してください。**
書式・振り分け・出典・差分形式はすべてスキル側の規則が優先です。

## モデルの目安
中位モデル＋思考中程度で十分です（書式遵守が主で、深い推論は要りません）。詳しくは MANUAL.md「4. LLMモデルの選び方」。

## 手順
1. 新しいClaudeチャットを開き、`shizuku-wiki.skill` を有効化する。
2. 対象ページの**現在のwikiソース全文**を貼る（スキル§0-1の要求。Fandomのソースエディタからコピー）。
3. `data/handoff/handoff_*.txt` の該当ブロックを貼る:
   - 「年表」ブロックは3行形式（【日付】【出来事の概要】【ソースURL】）のまま貼り、「年表に追記して」と依頼する。
   - 「名言・迷言」ブロックは逐語確定済みの発言＋出典URLを貼り、「名言・迷言に追加して」と依頼する。
   - 「回収成立」ブロックは、既存の年表行への**括弧書き追補**（例: 「（2026-02-10にしずくが目標を宣言していた）」＋両出典）を依頼する。
   - 「機能」「プロフィール補足」は紹介ページの該当節ソースと一緒に渡し、加筆案を依頼する。
4. 出てきた**差分**を目視 → Fandomの編集画面に反映 → 「変更を表示」で確認 → 保存。
5. スキル§3-6に従い、使った出典URLを https://web.archive.org/save/ に保存する。

## してはいけないこと
- 逐語未確定（⚠つき）の発言を名言として起草させる。
- handoffに無い事実を口頭で足す（足すなら出典もセットで）。
