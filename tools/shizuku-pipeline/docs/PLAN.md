## 1. 完成しているもの（実装＋実データ検証済み）

**スクリプト（scripts/、全て標準ライブラリ・構文チェック済み）**
- `shizulib.py` … 共通ライブラリ（パーサ、JST、JSONL I/O、正規化、設定ローダ、ID）。
- `s0_intake.py` … 再帰探索・命名揺れ吸収・info.txt基準・SBV/SRT両対応・OCRチャット認識・欠落重要度分け・known_absent/relations反映・`--dry-run`/`--verbose`。
- `s1_normalize.py` … 文再結合・辞書(norm列のみ)・JST変換・シグナル4種・X月別再構築・アーカイブ関係でevent_date付与。
- `s2_pack.py` … 抽出パック生成、`--all`一括＋WORKLIST、`--max-chars`自動分割、`--status`進捗、配信固有の注意（OCR/アーカイブ）自動挿入。
- `s2_ingest.py` … カード検証取込、逐語の機械検証（ASR強制false／原文照合／OCR不可）、安定ID・重複除外、open台帳登録、アーカイブ日付補正、`--file`自動検出。
- `s3_match.py` … 台帳照合、**ペア単位で順序非依存**、related付与、`--ingest`/`--list-open`。
- `s4_packet.py` … レビューパケット生成（A〜F、名言30日熟成、in_review管理、ref下敷き生成）。
- `s5_apply.py` … チェック反映（VERIFY/ADOPT/DROP/KEEP/CLOSE）、台帳open→closed移動、handoff生成。
- `doctor.py` … データ不備検査（D01〜D13）、字幕形式・OCR・アーカイブ・欠落重要度を反映。

**プロンプト（prompts/）**: `extract_stream.md` / `extract_x.md`（保存名の指示付き）/ `match_pairs.md` / `draft_wiki.md`。
