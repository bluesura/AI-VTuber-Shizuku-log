# 関係性カード抽出プロンプト

## 目的
「ユーザー名＋コメント＋かんけいラベル＋アイコンごとの増減値」が1枚のカードにまとまった画像を複数枚読み込み、内容をスプレッドシートに貼り付けられるシンプルな一覧（タブ区切り）に変換する。

## 入力の仕様
- 1枚（または複数連結された）画像の中に、ユーザーごとのカードが複数並んでいる。
- 各カードには以下の要素が含まれる：
  - ユーザー名（@から始まる表記）
  - コメント本文
  - 「かんけい」ラベル（例：顔見知り）
  - 1つ以上のアイコン付きバー。バーの右端に増減値（例：+1、+2、-2）が表示されている
- 複数の画像を投げ込む場合、スクロールしながら撮影した連番画像として時系列順（投げ込んだ順）に並んでいるものとして扱う。前後の画像間でカードが重複して写っていることがある。

## 抽出対象（カードごとに）
1. **ユーザー名**：`@`込みでそのまま記載
2. **コメント本文**：表示されている通り正確に書き写す
3. **かんけい**：表示されているラベルをそのまま記載
4. **アイコンと数値**：カードに表示されているアイコンのみを対象にする（表示されていないアイコンは出力しない）。1枚のカードに複数アイコンがある場合は、アイコンごとに1行ずつ出力する。
   - アイコン種別（表示されているもののみ）
     - ❤️ ハートマーク
     - ✨ キラキラマーク
     - 👥 人が複数重なっているマーク
     - ⚖️ 天秤のマーク
     - 🛡️ シールドのマーク
   - 数値：バー右端に表示されている符号付きの数値をそのまま記載（例：+1、+2、-2）。バー上のマーカー位置（到達度合い）は読み取らない。

## 重複カードの扱い（重要）
- 複数の画像にまたがって同じカード（同一ユーザー・同一コメント・同一かんけい・同一アイコン内容）が写っている場合は、**初めて登場した画像で1回だけ**処理し、以降の画像に同じカードが写っていても出力しない。
- 同じユーザーが別のタイミングで別のコメント・別の数値でカードを出している場合は、別カードとして扱いすべて出力する。

## 出力形式
- スプレッドシートにそのまま貼り付けられる **タブ区切り形式（TSV）**
- 列は次の5つ：`ユーザー名	コメント	かんけい	アイコン	数値`（各列の間はタブ1つ）
- 1枚のカードに複数アイコンがある場合は、ユーザー名・コメント・かんけいを繰り返して行を分ける
- 1行目にヘッダーを入れる
- 並び順は時系列（カードの登場順→画像の投げ込み順）を維持する

## 不明点があった場合
- アイコンの種類や数値がぼやけて判別できない場合は断定せず「不明」と記載する
- コメント本文の一部が読み取れない場合は、読める範囲を書き写し、読めない文字は `[?]` と記載する

## 出力例（添付画像1枚のケース）
```
ユーザー名	コメント	かんけい	アイコン	数値
@サーモン-v3x	しずくから見える風景を見てみたい	顔見知り	❤️	+1
@サーモン-v3x	しずくから見える風景を見てみたい	顔見知り	✨	+2
@サーモン-v3x	しずくから見える風景を見てみたい	顔見知り	🛡️	-2
```
