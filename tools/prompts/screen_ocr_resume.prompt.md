このリポジトリのしずくの画面OCRを続きから実行してください。

1. `AGENTS.md`、`Readme.md`、`tools/workflows/screen_ocr_progress.md`、`tools/workflows/Visual Chat-Timeline Syncの手順書.md` のローカルOCR節を読んでください。作業対象に近い `AGENTS.md` があればその範囲にも適用してください。
2. 進行チェックリストを、`logs/youtube/` の `*.info.txt` と `*.screen-ocr.txt`、`tools/scripts/screen_ocr_layouts/`、`outputs/shizuku-screen-ocr/` の実ファイルと照合してください。動画を指定した場合はその1本を対象にしてください。指定がなければ、完了済み・別エージェント担当中の動画を飛ばし、公開日順で次の1本を処理してください。耐久配信の前後半は別々の動画IDとして、前半から進めてください。
3. 再開地点を確認し、取得済みの映像や完了したOCR区間を再利用してください。冒頭・中盤・終盤を見て、画面に表示されるしずくの現在の発言欄だけを切り抜きます。待機画面・終幕・視聴者コメント・依頼文の欄を外し、短い区間で見切れやノイズを確認してから、既存のローカルOCRツールをCPUで実行してください。長時間配信は手順書の区間分割を使い、完了した区間から記録してください。
4. OCRの語句は画面の証拠にひも付け、誤認識や欠落を推測で補わず `[要確認]` を残してください。最終候補の時刻順と確認画像を照合し、既存ログを保護したうえで、対象動画フォルダに `<動画ID>.screen-ocr.txt` を追加してください。取得・生成日時、ツール設定、フレーム照合、本文のSHA-256は `verification.json` に記録してください。
5. 進行チェックリストを更新し、保存ファイル、処理範囲、件数、要確認件数、確認結果を報告してください。中断した場合は、どこまで保存したかと再開地点を作業フォルダとともに記録してください。今回の実行範囲は画面OCR1本です。
