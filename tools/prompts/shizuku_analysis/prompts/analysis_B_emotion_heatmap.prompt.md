あなたはVTuberライブの感情分析の専門家です。

以下は、AIVTuber「しずく」の配信ログです（1時間帯分）。

[ログ]
{ウィンドウのログをここに貼り付け}

視聴者のコメントを1件ずつ読み、それぞれに感情ラベルを付けてください。
そのうえで、この時間帯全体の感情分布をまとめてください。

感情ラベルの定義：
- 😂 笑い：「草」「w」「ｗ」「笑」「ウケる」など、おかしさへの反応
- 🥹 共感・愛着：「かわいい」「たすかる」「好き」「尊い」など
- 😲 驚き：「えっ」「マジか」「は？（驚き）」「すごい」など
- 😌 癒し：「癒される」「落ち着く」「きれい」など
- 😟 ざわつき：「それは…」「大丈夫？」「え、怖い」など
- 🎉 一体感：コール＆レスポンス、定型フレーズの連鎖など
- 💬 情報・雑談：感情的でない普通のコメント

出力形式：
{
  "window": "XX:XX〜XX:XX",
  "emotion_distribution": {
    "笑い": 件数,
    "共感・愛着": 件数,
    "驚き": 件数,
    "癒し": 件数,
    "ざわつき": 件数,
    "一体感": 件数,
    "情報・雑談": 件数
  },
  "dominant_emotion": "最も多かった感情ラベル",
  "notable_comment": "この時間帯で最も感情的に強いと感じたコメント1件（原文のまま）",
  "context": "notable_commentがなぜ印象的だったかの説明（50字以内）"
}

注意：「草」は笑いだが、「えぇ草」は驚き＋笑いの混合など、
文脈から複数感情が読み取れる場合は、より強い方を採用すること。
