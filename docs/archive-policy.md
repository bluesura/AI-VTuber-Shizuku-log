# ログの保存と検証の方針

このリポジトリは、有志による非公式アーカイブです。GitHubには、収録した資料と出所・加工・確認の記録を残します。Fandom Wikiでは、確認できた事実を読者向けに整理し、元動画の該当時刻や公式発表などへたどれる出典を添えます。Wikiの公開規則とページごとの書き方は、編集スキルを参照してください。 [Wiki編集スキル](../tools/skills/shizuku-wiki/SKILL.md) · [外部Wikiとの連携](../tools/skills/shizuku-wiki/references/external-wikis-sync.md)

## 収録範囲と欠落

2026年11月23日に、リポジトリ内で確認できた範囲です。範囲の両端は収録資料で確認できた最古・最新の日付です。期間内に欠落や資料の少ない時期があります。

| 媒体 | 確認できた期間・件数 | 保存している資料 |
| --- | --- | --- |
| [YouTube](../logs/youtube/) | 2023-01-19〜2023-10-31（49件）、2026-02-01〜2026-10-31（58件） | 動画情報の動画IDで集計。動画ごとに取得できた字幕、ライブチャット、通常コメントを保存。一部にローカルASRや画面から復元したチャットがある。 |
| [X](<../logs/twitter(x)/>) | 2023-01-23〜2023-11-01（1,621行）、2024-01-01〜2024-05-24（4行）、2026-01-06〜2026-05-20（2,641行） | TSV内のX投稿URL行を集計。日付はJST。投稿日とスナップショット日を別の列に記録している。2025年ファイルは「なし」の記録のみ。 |

- YouTubeの定期更新は対象チャンネルの終了済み配信を対象とする。予約枠と配信中の枠は対象外。視聴者・他の配信者・切り抜き・二次創作・周辺のSNS投稿は網羅的な収集対象外とし、調査で必要な場合は公開して差し支えないURLや匿名化した傾向を記録する。
- 動画情報や字幕、チャットの欠落理由が分かった場合は、対象・理由・確認日を調査記録に残す。既存の動画別の欠落・再公開の記録も参照する。 [既知の欠落](../tools/shizuku-pipeline/config/known_absent.tsv) · [動画どうしの関係](../tools/shizuku-pipeline/config/stream_relations.tsv)
- 既存の匿名化を維持する。一般視聴者の個人を特定できる生ログ、非公開投稿や私信、匿名化前の対応表は公開用資料の対象外とする。公開URLや匿名化済みの引用でも、原文検索などで個人を特定できる場合があるため、掲載範囲を絞る。
- 字幕やチャットなどの文字資料で確認できる範囲は、収録された文面と時刻に限られる。声色、画面演出、発言と画面の同期、収録されなかった反応は、必要に応じて元動画で確認する。動画が失われたときは、残存資料で検証できる範囲を記録する。音声・映像の保存や公開を別途検討する場合は、権利者への帰属、利用条件、個人を特定できる情報の有無を確認する。

## 取得・加工・確認を記録する

| 記録する項目 | 記録のしかた |
| --- | --- |
| 元資料と該当箇所 | 資料名、元URL、動画IDや投稿ID、リポジトリ内の参照先を記録する。映像・音声に関する主張は該当時刻や区間も添える。再公開版のタイムスタンプはその版の動画IDに結び付ける。 |
| 資料種別と日時 | 投稿者提供字幕、YouTube自動字幕、ローカルASR、OCR、ライブチャット、説明欄などを区別する。公開日・取得日時・生成日時はそれぞれ記録する。既存資料で根拠が見つからない値は「不明」と記し、拡張子だけで字幕の作成者を判断しない。 |
| 取得状況 | 「取得済み（0件を含む）」「未取得」「取得失敗」「元資料の欠落を確認」「収集対象外」「不明」を区別する。記録の欠落から、出来事や反応がなかったとは判断しない。 |
| 加工履歴 | 元資料への参照、変換・匿名化・補正・再生成の別、確認できた実施日時、ツールやモデルの版・設定を残す。整形済みテキストや要約から元資料へ戻れるようにする。 |
| 主張と確認段階 | 誰が何を述べたか、資料が主張のどこまでを支えるか、何を人間が確認したかを記録する。未確認の関連付けやAIの推論には `ai_hypothesis`、人間が資料と照合した事実には `observed` を調査メモ上で使う。 |

取得や加工を自動記録できない場合は調査記録に書く。原資料や匿名化済みの収録時点の文面を保持し、検索用表記や補正は別に残す。しずく特有の言い間違いや言い回しを引用する場合は、人間が元の音声や画面を確かめ、確認できた語句をそのまま残す。 [既存のログ圧縮手順](../tools/workflows/Wiki記事用の配信ログ圧縮.md)

## Wikiに渡す根拠

- 本人発言は、発言者がそのように述べたことの根拠になる。機能の実演、運営が発表した予定、確認できた実装仕様は、それぞれ画面や開発・運営側の資料で裏付ける。同じ発表を転載した複数ページも、元の発表まで戻って確かめる。
- 後日の出来事と過去発言は、確認できた日付順に記す。記憶・意図・因果の説明には、その関係を直接示す一次資料を添える。AIの仮説は調査メモに残し、Wikiの確定本文案は人間が確認した範囲で作る。
- 掲載を判断するときは、話題になった場面のほか、技術上の失敗、休止や再開、運用の変化も調べる。視聴者の反応を記す場合は、その場で確認できた範囲や集計対象を示す。
- Wikiの出典には読者が確認できる元資料を示す。取得履歴、リポジトリ内の参照先、確認メモは編集作業に使う。外部Wikiや百科事典で別の説明を見つけた場合は、元資料に戻り、その媒体の編集方針に沿って訂正を検討する。 [記事ワークフロー](../tools/skills/shizuku-wiki/references/article-workflow.md)

## 既存ログでの試行

### YouTube字幕の例

- **本文例**　2026年10月31日に、タイトルに「V2.5」を掲げた配信が公開された。日付とタイトルは動画情報で確認した。 [動画](https://www.youtube.com/watch?v=13GzMhFse0A) · [動画情報](<../logs/youtube/2026/2026-10-31_【V2.5】ただいま。新しくなったしずくを見てください【AI しずく】/13GzMhFse0A.info.txt>)
- **確認待ち**　字幕の04:45〜04:57には、休止中の記憶についての発言候補がある。音声を確認したら発言として記述できる。システムの保存仕様を扱うなら、対応する技術資料が要る。このSRTの取得日時・投稿者提供か自動生成か・変換履歴は不明。 [該当時刻](https://www.youtube.com/watch?v=13GzMhFse0A&t=285s) · [保存字幕](<../logs/youtube/2026/2026-10-31_【V2.5】ただいま。新しくなったしずくを見てください【AI しずく】/13GzMhFse0A.ja.srt>)

### ローカルASRの例

- **取得・加工履歴**　ASRの見出しで、2026年11月1日11:11:17（JST）に speech.cpp のモデル `qwen3-asr-1.7b` で再生成したことを確認できる。元音声の取得日時とエンジンの版番号は不明。 [保存したASR](<../logs/youtube/2026/2026-09-13_【歌枠】久しぶりの歌枠！リクエスト曲も歌います【AI しずく】/u2T4jUpRDlM.transcribe.txt>)
